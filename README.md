#  Библиотека игр

Учебный проект на Python с GUI-интерфейсом на Tkinter.  
Система учёта игровой библиотеки с фильтрацией, поиском и сохранением в CSV.

##  Возможности

-  Просмотр всех игр из базы (~300 реальных игр)
-  Поиск по названию (по подстроке)
-  Фильтрация по жанру
-  Фильтрация по годам выпуска
-  Фильтрация по цене
-  Добавление новых игр (с сохранением в CSV)
-  Сортировка по клику на заголовок таблицы
-  Тёмная фиолетовая тема

##  Технологии

- **Python 3.15**
- **Tkinter** — GUI
- **CSV** — хранение данных
- **ООП** — классы `Game`, `GameLibrary`, `GameApp`
- **Обработка ошибок** — кастомные исключения, валидация ввода
